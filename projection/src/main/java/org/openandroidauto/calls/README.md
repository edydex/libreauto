# Calls

Calls is off until the user explicitly enables Contacts and Phone access in the phone's **Calls setup** screen. Main does not request either permission automatically. Disable Calls there to stop contact access; Android's app permission settings can revoke the grants too.

The panel queries Android's phone-number contact rows on demand. Favorites are Android starred contacts. Queries and results are bounded, asynchronous and memory-only; there is no contact database, photo fetch, network request, contact writer or call-log reader. Closing the tab cancels its query and invalidates pending search dictation and call confirmations. Cancellation is sent by a separate worker; new queries refuse while cancellation is still returning. A provider that ignores Android cancellation can retain its single query/cancellation workers until it returns; no UI thread waits for those workers.

Typing or optional dictation searches contacts only. Each phone-number row is selected separately, then the panel displays its name, label and number with **Call** and **Cancel**. Call re-queries the exact provider row, refuses changed identities or fields, and rechecks opt-in, permissions, active projection, normal lock state and basic telephone capability. Only that explicit button can invoke `TelecomManager.placeCall`; it leaves the phone account and speakerphone extras unset. Android owns SIM/eSIM availability and selection, the actual call, call audio and in-call controls. A returned call request does not prove a SIM exists or a call connected. The app does not become the default dialer and has no in-call service.

Only ordinary 7–15 digit telephone numbers, optional leading `+` and visual separators are accepted. Emergency/short/service codes, pauses, waits, extensions, URI/SIP addresses and other dial modifiers must use the phone's normal dialer. Preview and disconnected sessions cannot place calls. Source checks do not establish real SIM, car HFP, secure-lock or call behavior; no real call has been made for these checks.

Android references: [TelecomManager.placeCall](https://developer.android.com/reference/android/telecom/TelecomManager#placeCall(android.net.Uri,%20android.os.Bundle)), [Contacts phone rows](https://developer.android.com/reference/android/provider/ContactsContract.CommonDataKinds.Phone), [Contacts provider](https://developer.android.com/identity/providers/contacts-provider).
